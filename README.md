# PuCold - Tipspromenad
Inclusion week

## Tipspromenad Webbplats

En webbplats för tipspromenad med integrerat Microsoft Forms-formulär.

### Funktioner

- Modern och responsiv design
- Integrering av Microsoft Forms för svarsinsamling
- Svensk språkanpassning
- Mobilvänlig layout
- Enkel att uppdatera med eget formulär

### Hur man använder

1. Öppna `index.html` i en webbläsare
2. Skapa ditt eget Microsoft Forms-formulär på [forms.office.com](https://forms.office.com)
3. Följ instruktionerna på webbplatsen för att bädda in ditt formulär

### Struktur

- `index.html` - Huvudwebbsidan
- `styles.css` - Stilmall för webbplatsen

### Live Demo

Öppna `index.html` i din webbläsare för att se webbplatsen lokalt.
